      One-time setup needed

      This console syncs every device in real time through a free Firebase (Firestore) project. Takes about 3 minutes:

      1. Go to console.firebase.google.com → Add project (free Spark plan is enough).
      2. In the project, open Build → Firestore Database → Create database → start in test mode.
      3. Go to Project settings → General, scroll to "Your apps", click the </> web icon, register an app, and copy the firebaseConfig object it shows you.
      4. Open this HTML file in a text editor, find the firebaseConfig block near the top of the script, and paste your values in.
      5. Re-upload/host the file. Every device that opens it will now share the same live data.

      Test mode keeps Firestore open to anyone with the config for 30 days — fine for getting started, but before going live long-term, tighten the rules, e.g.:

      rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true; // replace with real auth checks later
    }
  }
}
